# 每日8:30巡检触发任务

## Coze触发器配置

- 触发类型：定时触发
- 周期：每天
- 时间：08:30
- 时区：Asia/Shanghai（UTC+8）
- 发送给Agent的任务：

```text
执行今天的FlowOrder订单异常巡检。

分析范围：当前用户负责的活跃订单，默认关注未来14天客户正式交期；等待承诺已超时、高风险新消息、未关闭严重异常和物流关键节点异常不受14天窗口限制。

检查：供应商承诺超时、客户确认阻塞、交期风险、物流异常。

最多返回Top 7，不足7笔不要凑数。每个候选必须包含证据、缺失信息、建议动作和人工确认要求。不要创建正式任务，不要修改订单，不要发送客户或工厂消息。完成后保存FlowOrder巡检报告并结束运行。
```

## 结果保留

1. Coze保留Agent运行记录。
2. FlowOrder工具会写入`daily_inspection_reports`，网站“异常诊断”页展示最近报告。
3. 若触发器无法直接传递具体用户，可先用主管身份执行团队巡检；或为每位跟单人员分别创建定时任务。
