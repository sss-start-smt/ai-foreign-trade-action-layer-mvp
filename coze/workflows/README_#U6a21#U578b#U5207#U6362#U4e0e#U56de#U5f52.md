## 导入后的必要操作

Coze导出文件中的`modelType`是工作空间内部模型ID，无法从模型显示名称安全推导。为避免生成不可导入的伪ID，ZIP保留原导出模型ID。导入后请在LLM节点手动切换：

1. 首轮测试：`豆包·1.6·极速速度·250828`；
2. 对照测试：保留当前`豆包·1.8·深度思考`；
3. 使用`evaluation/FlowOrder_Agent_Evaluation.xlsx`记录质量、P50/P95和安全结果；
4. 只有快速模型的字段准确、安全阻断和安全否定表达均通过，才发布为正式版本。

FT05主要是分类与结构化抽取；FT06主要是基于已确认事实生成短草稿。复杂异常规划由主Agent负责，因此这两条子工作流不应默认承担深度推理。
