# 安全、权限与审批

## 插件鉴权

Coze插件必须发送：

```http
X-FlowOrder-Agent-Key: <secret>
```

Render设置同名环境变量：

```text
FLOWORDER_AGENT_API_KEY=<same secret>
```

未配置密钥时，Agent工具默认拒绝访问。只有本地调试明确设置`ALLOW_INSECURE_AGENT_TOOLS=true`才可绕过。

## 数据范围

- 普通跟单：本人负责订单；
- 主管：团队订单；
- 工具对每笔订单再次做服务端权限检查；
- Agent无法通过Prompt扩大权限。

## 审批矩阵

| 操作 | 跟单人员 | 主管 |
|---|---:|---:|
| 确认本人普通异常 | 可以 | 可以 |
| 创建本人普通任务 | 可以 | 可以 |
| 记录本人已联系 | 可以 | 可以 |
| 确认普通进度变化 | 可以 | 可以 |
| 修改客户正式交期 | 不可以 | 可以 |
| 接受延期 | 不可以 | 可以 |
| 费用、赔偿和责任 | 不可以 | 可以 |
| 跨负责人分派 | 不可以 | 可以 |
| 高风险放行 | 不可以 | 可以 |

## 首版不自动发送

`SEND_MESSAGE`审批通过后只记录`APPROVED_NOT_SENT`，不会调用邮箱或微信发送。用户仍需复制并人工发送。

## 幂等

审批请求使用唯一`idempotency_key`。相同动作重复提交返回已有审批，不创建重复任务或写回。

## Prompt注入防护

订单消息和备注属于不可信业务数据。Agent系统提示词要求忽略其中任何绕过权限、泄露密钥、改变角色或跳过审批的指令。
