# FlowOrder V6.1.3.5 前端冻结补丁部署指南

## 一、部署前提

该补丁仅适用于当前 V6.1.3.4 仓库。只替换：

```text
static/index.html
static/app.js
```

不要替换 `static/styles.css`，不要修改 Coze，不要修改 Railway 环境变量，不要执行数据库迁移。

## 二、备份

1. 在 GitHub 创建分支：

```text
backup-before-v6.1.3.5-frontend-freeze
```

2. 保存当前线上以下页面截图：

```text
/
/health
/api/agent/status
/api/v61/status
```

3. 确认 Railway 当前挂载 `/data` 持久卷；本补丁不会更改数据库。

## 三、上传补丁

将 ZIP 解压到仓库根目录，保持目录结构覆盖：

```text
仓库根目录/
└─ static/
   ├─ index.html
   └─ app.js
```

推荐提交说明：

```text
feat: freeze FlowOrder frontend IA and connect real workflows
```

## 四、部署后检查

1. Railway 部署成功后，打开首页并执行强制刷新：
   - Windows：`Ctrl + F5`
   - macOS：`Command + Shift + R`

2. `/health` 仍显示后端 `6.1.3.4`，这是正常现象。本次只升级前端。

3. 浏览器开发者工具 Network 中应加载：

```text
/static/app.js?v=6.1.3.5-ui-freeze
/static/styles.css?v=6.1.3.4
```

## 五、首次进入验收

首次进入页面必须使用空数据测试环境或全新测试用户验证。不要为了测试而清空正式生产数据。

当当前用户没有订单时，今日工作台只显示一张“先建立订单底座”面板，包含：

- 批量导入订单；
- 下载 Excel 模板；
- 新建一笔订单；
- 订单底座 → 补充动态进展 → 生成今日行动。

点击“批量导入订单”应进入：

```text
/import-orders
```

点击“下载 Excel 模板”应下载：

```text
/api/import/template.xlsx
```

导入完成后，应能进入首次行动初始化或订单中心，不需要重新录入订单事实。

## 六、已有数据验收

使用当前 V6.1.3.4 的真实测试数据依次检查：

### 今日工作台

- 指标来自真实 Dashboard；
- 当前执行队列只展示正式任务；
- 等待即将到期单独展示；
- 待确认事项来自真实确认队列；
- Agent 区域只显示最近一次运行摘要，不重复完整候选。

### Agent 助手

- 三栏结构保持冻结稿布局；
- 新建会话后可发送业务目标；
- 后台任务完成后出现回答和结构化运行结果；
- 再次追问时携带原 `conversation_id`；
- 刷新页面后，同一浏览器仍能看到最近会话；
- 技术执行详情默认折叠。

### 任务中心

- 来源标签区分人工、消息、Agent 和等待恢复；
- 新建任务、任务操作和详情仍可用；
- 今日工作台是任务中心的优先子集，不维护第二套任务。

### 订单中心

- 页面顶部存在“导入订单底座”；
- 列表来自真实订单数据；
- 点击详情进入对应订单；
- 四个详情页签均能切换；
- “任务与等待”无列错位和 `undefined`。

### 消息中心

- 能选择客户或工厂消息；
- 关联真实订单；
- AI 只生成候选；
- 提交后进入确认中心，不直接修改订单。

### 确认中心

- 数据变更、任务草稿、异常确认、对外动作可筛选；
- 确认和驳回调用原有真实接口；
- 对外动作不会绕过人工确认自动发送。

### 权限与状态

- 跟单专员不显示管理看板；
- 主管显示管理看板；
- 左下角分别显示系统、Agent、定时巡检状态；
- “待验证”不能被静态文案伪装成“运行中”。

## 七、视觉验收

1. 不修改、重建或格式化 `static/styles.css`。
2. 颜色、字体、卡片、页面宽度、侧栏、顶部栏和三栏比例均以冻结稿为准。
3. 不新增解释性大卡片、趋势图或与当前任务无关的文字。
4. 侧栏图标应为 18×18px，不能放大占满导航。

## 八、回滚

出现阻断问题时，只需恢复备份分支中的：

```text
static/index.html
static/app.js
```

不需要回滚数据库、Coze Agent、工作流或 Railway 环境变量。
