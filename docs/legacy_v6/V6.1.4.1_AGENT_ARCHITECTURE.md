# V6.1.4.1 Agent架构

```text
用户自然语言
→ 混合意图路由器
  ├─ 提取时间、Top N、订单、排名、否定限制
  ├─ 拆分多个目标与依赖
  ├─ 模糊时澄清
  └─ 不处理权限提升
→ 受控执行器
  ├─ 标准风险：共享FT04规则 + 异常证据
  ├─ 批量进展：字段候选
  ├─ 任务：草稿 + 审批
  └─ 开放问题：Coze
→ 结果观察与停止
  ├─ 目标完成
  ├─ 候选待确认
  ├─ 权限不足
  ├─ 信息不足
  └─ 开放请求超时
→ 前端三栏工作台
```

## Agent属性

FlowOrder仍是受控任务型Agent，因为系统会：

- 接受目标而不是要求用户选择工作流；
- 拆解多个目标；
- 选择工具；
- 根据工具结果决定下一步；
- 读取上一轮结构化运行；
- 在需人工确认时停止；
- 对开放目标调用模型。

规则不是Agent的替代品，而是Agent调用的可靠业务能力。
